# class Rect <Badge type="info" text="public" />
A class to represent a rectangle

## #add(other) <Badge type="info" text="public" />

<p>combines rectangle with another rectangle</p>

#### Arguments

*  _other_ - another Hokusai::Rect to add.

### Returns

Returns a new Hokusai::Rect


## #intersect?(other) <Badge type="info" text="public" />

<p>Does this rectangle intersect with (other)?</p>

#### Arguments

*  _other_ - a Hokusai::Rect to compare

### Returns

Returns boolean


## #includes_y?(y) <Badge type="info" text="public" />

<p>does this rectangle include (y)?</p>

#### Arguments

*  _y_ - a y coordinate

### Returns

Returns boolean


## #includes_x?(x) <Badge type="info" text="public" />

<p>does this rectangle include (x)?</p>

#### Arguments

*  _x_ - x coordinate

### Returns

Returns boolean
