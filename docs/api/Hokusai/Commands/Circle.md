# class Circle < Commands::Base <Badge type="warning" text="internal" />
Command to draw a circle.
Radius starts from [x,y] and moves outward from center

## #initialize(x, y, radius) <Badge type="warning" text="internal" />

<p>Circle constructor</p>

#### Arguments

*  _x_ - x coordinate
*  _y_ - y coordinate
*  _radius_ - circle radius


## #color=(value) <Badge type="info" text="public" />

<p>sets the circle color.</p>

#### Arguments

*  _value_ - a Hokusai::Color or Array of Int

### Returns

Returns nothing
