# class Publisher <Badge type="warning" text="internal" />
An event emitter

## #add(listener) <Badge type="warning" text="internal" />

<p>Adds a listener that subscribes to events emitted by this publisher</p>

#### Arguments

*  _listener_ - a Hokusai::Block


## #notify(name, args, kwargs) <Badge type="warning" text="internal" />

<p>emits `event` with `**args` to all subscribers</p>

#### Arguments

*  _name_ - event name
*  _args_ - splatted arg array
*  _kwargs_ - any kwargs to send
